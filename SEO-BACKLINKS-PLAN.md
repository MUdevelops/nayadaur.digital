4. GitHub organisation / profile README linking to the site; Behance or Dribbble for design samples.
5. Pakistani business directories (Okara chamber / local directories, Yellow Pages Pakistan style sites).

Do NOT buy backlinks or use link farms. Google penalises this and can remove the site from search.
